# v0.2.3 — Sync upstream 0.1.29: member recovery on Harness 0.2.2

Stable release on npm `latest`; the previous stable is [v0.2.2](./v0.2.2.md). Requires DeepSeek Harness `>=0.2.1-rc.2` — unchanged, so upgrading needs no configuration change.

- **Member model fallback works again on Harness 0.2.2.** The host now owns the next-step route in the Agent model API, so a recoverable provider error switches the member to its configured fallback route through that API. The switch is persisted only while the recovery is still live, and a pending recovery is cancelled when the member is disposed.
- **A model output limit settles the task.** When a member's turn ends because the model hit its output-token limit, the open attempt becomes `failed` with a `MAX_TOKENS` reason instead of staying open forever. The captain can then retry or reassign the work.
- **The activity panel polls only what the current session owns.** Requests are scoped to the open session, unchanged responses are reused through validators, and every session keeps its own snapshot when you switch back. The archive list still loads once per controller, so a team archived before the page opened stays listed and deletable.
- **Delivery audits no longer block the host.** Workspace audits run in a worker and compare content digests, so a reviewed file rewritten with the same size and modification time is still detected, and a stale passing verdict is never advertised as current.
- **Team status mail binds to the authorized team snapshot**, so a status reply cannot be assembled from a team the captain no longer owns.
- **Release safety.** Publishing now refuses a release tag that points at a different commit than the one that was verified.

Members stay resident after their turn, as before; the output-limit scenario covers both the resident continuation and the cold-resume shape.

```sh
dsh plugin --profile web add --save-exact @chenxu233/dsh-agent-teams@0.2.3
```

Replace `web` with your CLI profile and restart that profile's Harness process after installing.

## 中文

npm `latest` 上的正式版；上一版为 [v0.2.2](./v0.2.2.md)。安装下限仍是 DeepSeek Harness `>=0.2.1-rc.2`，升级不需要改配置。

- **Harness 0.2.2 上成员模型回退恢复。** 新宿主把下一步路由交给 Agent 模型 API 管理，可回退的 provider 错误现在通过该 API 切换到配置的备用路由；切换只在恢复仍然有效时落库，成员销毁时会取消待执行的恢复。
- **模型输出上限会把任务结算掉。** 成员因为触顶结束回合时，未完成的 attempt 会以 `MAX_TOKENS` 失败收尾，队长可以重试或改派，而不是等一个永远不会关闭的任务。
- **活动面板只轮询当前会话拥有的团队。** 请求按打开的会话收窄，未变化的响应通过校验器复用，切回会话时各自保留快照；归档列表仍在控制器启动时拉取一次，页面打开前已归档的团队依然可见、可删除。
- **交付物审计不再阻塞宿主。** 工作区审计在 worker 中运行并按内容摘要比对，尺寸和修改时间都没变的改写同样能被发现，过期的通过结论不会被当成当前状态展示。
- **团队状态邮件绑定到已授权的团队快照**，队长已经不属于该团队时不会拼出一封状态回信。
- **发布安全。** 发布时会拒绝指向「与验收提交不同」的 release tag。

成员在回合结束后仍然驻留，与之前一致；输出上限场景同时覆盖驻留续跑与冷恢复两种形态。

```sh
dsh plugin --profile web add --save-exact @chenxu233/dsh-agent-teams@0.2.3
```
