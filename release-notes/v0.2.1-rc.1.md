# v0.2.1-rc.1 — Verified tag-driven publishing

Prerelease on npm `next`; the stable channel and the `latest` dist-tag stay on [v0.2.0](./v0.2.0.md). Recommended host: Harness `0.2.1-rc.4`; every host at or above `0.2.1-rc.2` is accepted.

- No functional changes: this release verifies the repository's tag-driven pipeline end to end — GitHub Actions runs the full verification matrix, publishes the exact verified tarball to npm through OIDC trusted publishing (no token, no OTP), and creates a GitHub pre-release.
- The publish workflow is scoped to `ChenXu233/dsh-agent-teams` and checks this fork's own npm `latest` before publishing.

From `0.2.1` on, a release is: bump the version, add the matching release note, commit, push the branch, then push the `v*` tag. The workflow does the rest.

```sh
dsh plugin --profile web add --save-exact @chenxu233/dsh-agent-teams@0.2.1-rc.1
```

Replace `web` with your CLI profile and restart that profile's Harness process after installation. The prerelease is opt-in; `latest` continues to resolve the stable `0.2.0` build.
